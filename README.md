# Text Search App

A React application that allows users to search through articles in real time, with matching keywords highlighted in the results.

## Features

- Live search as you type
- Keyword highlighting in titles
- Shows number of results found
- Clear search button

## Tech Stack

- React
- Vite
- Tailwind CSS

## How to Run

1. Clone the repository:
   git clone https://github.com/ahmadanka1/text-search-app.git

2. Navigate into the project folder:
   cd text-search-app

3. Install dependencies:
   npm install

4. Start the development server:
   npm run dev

5. Open your browser and go to:
   http://localhost:3000
